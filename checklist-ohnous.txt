Le fond doit toujours être :

## Cartes

Toutes les cartes doivent respecter les règles suivantes :

* fond blanc ;
* ombre légère ;
* bordure discrète si nécessaire ;
* espacement homogène ;
* coins légèrement arrondis.

## Border radius

Ne dépasse jamais :

10 px

* avatars ;
* boutons ronds ;
* badges circulaires.

Évite les coins trop arrondis.

## Inputs

Tous les formulaires doivent suivre une grille propre.

Largeurs autorisées uniquement :

* 25 %
* 50 %
* 100 %

Ne jamais utiliser des largeurs incohérentes.

Les champs doivent toujours être parfaitement alignés.

Respecter un espacement identique entre chaque ligne.

Que les inputs numbers ne puissent pas avoir l'icone par défaut du navigateur qui permet de pouvoir augmenter ou diminuer la quantité

---

## Texte

Pour tous les champs de saisie :

minimum **16 px**

afin d'assurer une bonne lisibilité sur mobile.

Pour le reste :

* hiérarchie claire des tailles ;
* jamais de texte trop petit.
* N'alignent jamais un text gras avec un text normal si celui-ci est un titre ou un nom et le reste est un detail du nom ou du titre ou quelque chose dans ce sens là, dans l'idéal il faudrait passer l'autre text à la ligne ou mettre un séparateur.
* Je ne veux pas de lien avec les underlines à moins que ce soit un lien qu'on a placé sur une description ou un message ou quelque chose de ce genre mais si c'est pour naviguer dans le site je veux que tu prenne en comptes le design et retire l'underline.


---

## Icônes

## Responsive

Le site doit être entièrement responsive.

Desktop :

* bonne utilisation des colonnes.

Tablette :

* réorganisation propre.

Mobile :

* priorité à une seule colonne lorsque nécessaire ;
* aucune coupure de texte ;
* aucun débordement horizontal ;
* aucun élément caché derrière un autre.

## Espacements

Conserver un rythme visuel homogène.
